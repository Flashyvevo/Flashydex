## Design (follow unless the code proves it wrong — say so in the report)
1. **FX record** `{ base:'EUR', quote:'USD', rate: string (decimal, e.g. "1.0834"), rateDate:'YYYY-MM-DD', provider:'frankfurter', fetchedAt: Instant }`. Provider: Frankfurter `https://api.frankfurter.dev/v1/latest?base=EUR&symbols=USD` (ECB reference rates, weekdays; verify the real response shape with curl first and paste it in the report). Cache in app storage (localStorage key `fdx.fx.EURUSD`, versioned JSON) — NOT in the user SQLite DB. Refresh if cached `rateDate` is older than 1 day and online; offline/failed → keep last verified record. **Stale** = rateDate > 7 days old → UI badge "FX rate from <date>". No cached rate → USD value for EUR-only cards is **unavailable** (honest state, counted as unpriced-in-USD with reason `fx_unavailable`), never a guess. Zero fabricated rates; no hardcoded default rate anywhere (a test asserts this by grepping for a literal like `1.08`? — no: assert behaviourally that with no FX record the result is null).
2. **Money math**: integer cents only. `convertCents(eurCents, rate)` with the rate as a decimal string parsed to scaled BigInt (e.g. 6 fractional digits), rounding half-up to the cent, deterministic; property tests for rounding and overflow (`MAX_CENTS`).
3. **Price selection** in `valuation.ts`: for display currency USD and an exact (variant, variantDetail) print: (a) tcgplayer `market` → `mid` (today's rule); (b) else cardmarket `mid` (EUR) × FX → USD with `source:'cardmarket'`, new optional fields on ValuationDto: `converted: true`, `originalCents`, `originalCurrency:'EUR'`, `fxRate`, `fxRateDate`, `fxProvider`, `quoteType:'market'|'mid'|'avg'`, `stale?: boolean`. EUR display: today's rule (cardmarket mid), and symmetric conversion from USD is NOT required for Phase A (keep EUR as is; say so in docs). Manual price still wins. Graded copies unchanged (no automatic value).
4. **Portfolio** (`portfolio.ts`): USD bucket now includes converted copies; add to `CurrencyStats` (additive, optional): `convertedCopies`, `convertedValueCents`, `staleFxCopies`, `fxUnavailableCopies`, `sourcePricedCopies`. Gain/loss: comparable only when cost currency == display currency OR the cost is converted with the same FX record (document which you did; prefer: cost in EUR vs value in USD → convert cost with the same rate and flag `converted`). Never double count tcgplayer+cardmarket for one copy.
5. **ServiceContext** gets `fx?: { get(base:'EUR', quote:'USD'): FxRecord | null }` (sync, already-loaded snapshot) so core stays pure/deterministic; the app loads/refreshes the record (`lib/fx/frankfurter.ts`, `lib/fx/store.ts`, `data/fx-hooks.ts`) and passes it in; dashboard/card-detail queries re-run when the FX record changes (react-query key includes rateDate).
6. **UI (minimal, keep existing design)**: dashboard value shows USD total as today; sub-line coverage: "N source-priced · N converted (FX <date>) · N unpriced" and a stale badge when applicable. Card details: "Estimated value $X" + source line "Cardmarket €21.40 → $23.19 · ECB rate 1.0834 (2026-11-07)" for converted, "TCGplayer market $X" for native. Owned rows: use the new USD value where they showed "—" for EUR-only. No new screens.

## Opus UX v2 requests S1–S9
- D12 (S1). Answered by API.md `CatalogInstallService` (checkManifest sizes, install with progress+AbortSignal, status, uninstall, rollback). Phases map to UX stages: downloading = `downloading`; verifying = `decompressing|verifying`; installing = `validating|prepared`; activating = `activating|validating_active|committed`; ready = `installed`; failed(reason) from `lastError.code` (HTTP_FAILED→network, PACK_HASH_MISMATCH→hash, PACK_SIZE_MISMATCH→size, PACK_INVALID/APP_UPDATE_REQUIRED→schema, STORAGE_FULL→space). Range resume: **no** in Phase 1 (interrupted install restarts the download; UX copy must not promise resume of bytes). `installedSize(lang)` = manifest entry `uncompressedBytes` of the installed version (approximate, labelled "about"). Card/set counts for the language picker come from manifest `counts`.

## Architecture readings (ADR-040–048 missing from DECISIONS.md)
- D22. Three DB files: `flashydex-user.db`, `catalog-en.db`, `catalog-ja.db`. No ATTACH reliance (device-storage research: plugin has no ATTACH) → app-level joins in core via the CATALOG-PACKS join plans; `DatabaseSet.user` + `DatabaseSet.catalog(language)`; an absent catalog = empty catalog reads, owned snapshots still render.
- D23. Two migration chains: `packages/core/migrations/user/` and `packages/core/migrations/catalog/` (catalog chain created by sonnet-tooling in Stage 0; sonnet-data inherits and must not diverge — the pack builder applies the same files).
- D24. Web = development/limited mode: the jeep/sql.js store holds DBs in memory; packs install on web (swsh3 dev pack is tiny); no full-catalog guarantee on web.
- D25. Backups: `.fdx` (IMPORT-EXPORT) supersedes PHASE1-ACCEPTANCE 49–51's "raw SQLite backup/restore" wording. Priority inside sonnet-data is JSON/CSV export+import first, `.fdx` create/restore after; if `.fdx` is unfinished `BackupService.capabilities()` returns `fdxCreate:false, fdxRestore:false, reason` and the UI shows the row disabled with that reason — never a fake success.
- D26. Per-card TCGdex sync (SyncService) is the secondary refresh/fill-in path; primary install = CatalogInstallService from `FLASHYDEX_MANIFEST_URL` (dev default `/dev-packs/catalog-manifest.json`).
- D27. Dev URLs: in `import.meta.env.DEV`, manifest `fullPackUrl`/`setIndexUrl` may be relative or `http://` (same-origin dev server); production requires `https://` per the manifest schema. `public/dev-packs/` must not ship in a production build (excluded at build time).
- D28. Ownership split Stage B: sonnet-data = `packages/core/**`, `packages/schemas/**`, `apps/mobile/src/data/**`, `apps/mobile/src/platform/**` (adapter fixes/wiring), `apps/mobile/vite.config.ts`. sonnet-ui = `apps/mobile/src/routes/**` (except `routes/dev/**`), `src/components/**`, `src/styles/globals.css`, `src/main.tsx`, `index.html`, `capacitor.config.ts`, `apps/mobile/package.json` (deps), `apps/mobile/e2e/**` (except tooling specs). Hook surface between them: API.md "Director notes — UI↔data hook surface".

## How to launch a Sonnet builder
Write `.agent/<role>-task.md` (self-contained: Context / Your files (ownership) / Do / Don't / Verify / Report-to-path), then run in the terminal tool with background=true and a generous timeout:
`hermes chat --oneshot -Q --provider anthropic -m claude-sonnet-5-5 --query-file .agent/<role>-task.md --max-turns 100 --run-budget 2400 > .agent/<role>-run.log 2>&1; echo "<role> exit $?"`
Use `--query-file`, not `-q`. A finished child's log ends with a `session_id:` line — poll with `grep -q "^session_id:" .agent/<role>-run.log` every 60–120 s (`sleep 90` in the foreground is fine). Never run two children that edit the same file at the same time.
